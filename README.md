# Antigravity Island 🏝️

Extension visuelle et corporelle pour l'agent Antigravity sur Windows.
Prend la forme d'une encoche / Dynamic Island ancrée en haut de l'écran, animée en 60 FPS avec PyQt6, pilotable à distance via WebSocket et serveurs d'outils (MCP).

## Fonctionnalités
- **Overlay Transparent & Fluide** : Toujours au premier plan, sans bordure, centré en haut de l'écran.
- **5 États Morphiques** : Idle, Listening, Thinking, Speaking, Action.
- **Pilotage Antigravity** : WebSocket bidirectionnel pour contrôler l'affichage et la voix.
- **Pointage & Vision** : Permet à l'agent d'attirer l'attention sur n'importe quel élément de l'écran.
